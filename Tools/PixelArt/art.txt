// Cobalt Cabinet production art source. Rebuild every output with: sh tools/regenerate.sh  (see STYLE_GUIDE.md, section 14)
// Every sprite is a 16x16 frame; a sprite's frames become one horizontal strip PNG (frame 0 on the left).
// "." is transparent. Keys are the 16 palette slots below (all used); never add a colour without updating STYLE_GUIDE.md.
// Look rules: no ink outlines; every character is a solid silhouette of at most 3 colours (one body hue plus white and/or ink
// details) and every pickup of at most 4, like an early-1980s hardware sprite. Legs, tails and sticks are 2px thick, except
// Peeper's legs and silk thread (1px), the hero's tapered tail tip and the fruit stems. Light comes from the top-left:
// shines sit on the top-left, shading on the bottom and right. The hero is the only large white figure.
//
// Palette table (contrast vs N; the tools need N, J, L/D and W/S in these roles, and K and Y to exist):
//   N  #060a1c  night       1.0:1  background and corridors, camera clear colour
//   J  #173596  cobalt      1.9:1  wall core          S  #4378f0  azure      4.9:1  wall bevel band, pellet glow, HUD digit shadow
//   L  #b8e4ff  ice        14.6:1  wall lit edge, pellet glint, HUD label   D  #2756d8  deep blue  3.2:1  HUD label shadow only
//   E  #0c1a52  navy        1.2:1  wall shade (2px)   W  #ffffff  white     19.7:1  hero, eyes, pellet core, HUD digits
//   K  #020410  ink         1.0:1  pupils, faces, Swirlpop's swirl groove, vignette tint
//   V  #c294ff  violet      8.4:1  Chase (Fangbat)    G  #bcf43a  lime      15.1:1  CutOff (Peeper)
//   M  #da609d  raspberry   5.8:1  Scared (Jitters)   T  #1fa858  jade       6.4:1  Random (Swirlpop), leaves and stems
//   R  #ff3b3b  red         5.6:1  hero neckerchief, red fruit, bell bow    Y  #ffcf3a  gold      13.3:1  bell, key, seeds
//   O  #ff8a1f  orange      8.3:1  orange rind, caramel, bell and key shading, cork    A  #ffb347  tangerine 11.0:1  orange flesh
@palette
N #060a1c night: background and corridors (camera clear colour; never drawn inside sprites)
J #173596 cobalt: wall core fill, always flat
S #4378f0 azure: wall bevel band, pellet glow on the shaded side, HUD digit shadow, points popup shadow, burst sparks
L #b8e4ff ice: wall lit edge, pellet glint, HUD label, burst rays and centre, potion brew
D #2756d8 deep blue: HUD label shadow only
E #0c1a52 navy: wall shade (2px) on the south and east faces
W #ffffff white: hero body, eyes, fangs, thread, sticks, shines, wall corner glint, pellet core and twinkle, burst core, HUD digits, points popup
K #020410 ink: pupils, faces, Swirlpop's swirl groove, melon seeds, debug-target rim and vignette tint (never an outline)
Y #ffcf3a gold: bell, key, strawberry seeds, caramel highlight
R #ff3b3b red: hero neckerchief, cherry, strawberry, apple, melon flesh, bell bow
O #ff8a1f orange: orange rind, toffee caramel, bell and key shading, potion cork
A #ffb347 tangerine: orange flesh
V #c294ff violet: Chase enemy (Fangbat) only
G #bcf43a lime: CutOff enemy (Peeper) only
M #da609d raspberry: Scared enemy (Jitters) only
T #1fa858 jade: Random enemy (Swirlpop) body; also pickup stems, leaves and melon rind
